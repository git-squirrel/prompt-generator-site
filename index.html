ASYNC PIPELINE

让 AI 润色，
藏在出图的时间里

开启 AI 润色后，下一组提示词会在当前图片采样的同时于后台准备。 润色的等待被生图覆盖，多组任务不再一组一组地排队。

  • 首组润色完成后，后续组边出图边润色
  • 多组批量任务总时长显著下降
  • 单组任务行为不变，随时可以关闭

LOCAL FIRST

数据默认留在你的电脑里

词库、身份设置、模板组、AI 配置与出图记录，全部保存在本地 data/ 目录的 JSON 文件里。没有账号，没有云端同步。

  • JSON 持久化刷新、重启都不丢，随时可读可备份
  • 独立导出 / 导入提示词、AI 设置、ComfyUI 设置分开管理
  • 只连你配置的服务除主动填写的 API 与 ComfyUI 地址外，不向外部发送数据

GET STARTED

三分钟，把工作台搬回本地

不需要数据库，不需要构建工具。有 Python 和浏览器就能跑。

1

克隆并启动服务

默认监听 8080 端口。Windows 用户也可以直接双击 start_server.bat。

2

配置 AI（可选）

填入 DeepSeek、Kimi、OpenAI 的 Key，或连接本地的 Ollama / LM Studio。

3

上传 ComfyUI 工作流（可选）

在 ComfyUI 里用 Save (API Format) 导出 JSON，上传后即可批量生图。

终端 · 快速开始 
# 1. 获取项目
$ git clone https://github.com/git-squirrel/prompt-generator.git
$ cd prompt-generator

# 2. 启动服务（Python 3.8+）
$ python start_server.py

# 3. 浏览器打开
→ http://localhost:8080
Windows 可双击 start_server.bat 无需数据库
建议使用 API 格式工作流

ComfyUI 右上角 Save (API Format) 导出的 JSON 解析最稳定；普通导出格式也能自动转换。

先本地，再云端
